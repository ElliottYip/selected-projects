# 独立作品

我设计并制作 AI 产品、创作工具和互动体验。这里收录四个独立项目，涵盖内容创作、企业协作、日常记录与游戏。

I design and build AI products, creative tools and interactive experiences. This collection brings together four independent projects, from creative work and team collaboration to everyday notes and games.

## 项目一览

| 项目 | 简介 | 了解项目 | 源码 |
|---|---|---|---|
| **RAFT Generator** | 在同一工作台中生成图片、视频和数字人内容，并管理创作素材 | [项目介绍](projects/raft-generator/) · [在线体验](https://generator.raft.xin) | 私有 |
| **Company OS** | 让人员与 Agent 围绕任务协作，管理权限、审批与执行记录 | [项目介绍](projects/company-os/) · [GitHub](https://github.com/ElliottYip/company-os) | 公开 |

| **金势牌馆** | 结合麻将元素、策略牌局与单人冒险的独立游戏 | [项目介绍](projects/jinshi-parlour/) | 私有 |

## 关于这些作品

四个项目均由我独立负责产品构思、设计、实现与后续迭代。每个项目页都记录了设计思路、具体工作和当前进展，并附有预览及架构说明。

I independently led each project from concept and design through implementation and iteration. The project pages cover the work, the decisions behind it and its current stage.

本仓库收录公开介绍与预览。源码按项目独立管理，仓库关系见[项目与仓库](docs/repository-map.md)。
