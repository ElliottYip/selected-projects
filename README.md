- 想看 AI 创作产品：从 **RAFT Generator** 开始。

- 想看移动端信息记录：看 **Raft Notes**。

每个项目页包含背景、个人工作、当前形态、预览和架构说明。项目中的开源依赖、字体与第三方组件遵循各自许可；“独立完成”指项目工作，并不表示所有底层依赖均为原创。
