## 项目概述

面向移动端的 AI 笔记产品，整合信息记录、语音转写、AI 整理与对话。

## 为什么做

零散记录需要在低操作成本下保存下来，并进一步整理成可以查找、继续讨论的信息。

- 设计并实现语音转写、AI 整理与对话的连续使用流程。
- 结合使用反馈持续迭代产品。
