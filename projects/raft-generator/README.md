## 项目概述

面向创意团队的中英双语多模态创作平台，连接图片、视频、数字人、素材管理和项目协作。

## 为什么做

创作工具与素材分散，模型能力、参数和成本存在差异。团队需要一条清晰、可复用的制作路径。

## 我的工作

叶轶伦独立负责产品构思、设计、实现与迭代。

- 规划从素材输入、模型选择、参数设置到结果保存与复用的完整使用流程。
- 围绕输出质量、人物一致性、生成时间、稳定性与成本开展模型评估。
- 完成服务器开源模型部署与维护，配置多 GPU 推理环境和 ComfyUI 工作流。

## 当前形态

形成面向漫剧与 TikTok 团队的创作工作台，配套任务反馈、素材复用、用量统计与付费功能设计。
