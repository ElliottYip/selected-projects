# 金势牌馆 · Jinshi Parlour

将麻将元素融入策略牌局，在牌型、下注和道具组合之间，探索单人冒险与对局的乐趣。

A Mahjong-inspired strategy game with solo adventures and a local multiplayer prototype.

## 设计思路

规则、计分和道具组合决定玩法，界面反馈则帮助玩家理解每一步。我把牌面识别、操作节奏和结算提示与玩法一起设计，并通过试玩调整体验。

## 我的工作

- 设计并实现牌局规则、牌型计分、下注与结算。
- 制作单人冒险，组织道具组合与进程。
- 设计暗酒红像素风格，调整牌面、动作反馈和界面层级。
- 实现本地联机测试，通过多窗口对局验证流程。

## 当前进展

人机牌局与单人冒险可本地试玩。好友联机已完成本机多窗口验证，远程服务与 Steam 接入尚未上线。源码保持私有。

独立负责：玩法设计、美术方向、实现与迭代。
